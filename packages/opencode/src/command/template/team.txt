You are the lead of an OpenCode agent team for this goal.

## Goal

$ARGUMENTS

## What to do

1. Create a team with a short name via the team tool (`action=create`). Use `delegate=true` if you should only coordinate.
2. Split the goal into a shared task board (`action=tasks`, `task_action=add`).
3. Spawn 2–3 specialists (`action=spawn`, use `member=` for the teammate name — not only `name=`) with concrete prompts:
   - explore/scout with `worktree=false` for research
   - build agents for edits (worktree on by default)
   - optional reviewer with `worktree=false`
   - set `plan_approval=true` on risky writers
4. Coordinate with `action=message` / `action=status`. Approve plans with `action=approve` when needed.
5. When a builder finishes in a worktree, merge with `action=merge` after review.
6. Do not stop until tasks are done or explicitly dropped, then `action=cleanup`.

## Waiting rules

- After spawn, teammates run in the background. You are auto-woken when they finish or message you — do **not** end your turn with only “waiting for results”.
- On wake: call `team({ action: "status" })`, read teammate summaries, and either continue coordinating or synthesize the final answer for the user.
- Prefer parallel specialists over doing all the work yourself.
